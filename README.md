# Aplicacao-NODEJS-Comidas
 ##Projeto em sala de aula, proposto na disciplina de Linguagens de Programação II, UNOESTE, FIPP.
Desenvolver um pequeno servidor HTTP em Node.js capaz de realizar operações de cadastro
de produtos de uma padaria utilizando roteamento e somente os Core Modules http, url e
fs.
Para a aplicação você deve criar um menu de cadastro de produtos por categoria, sendo elas:
- Pães (nome, tipo de fermentação, ingredientes, preço por kg)
- Confeitaria (nome, tipo de doce: bolo; doce fino; biscoitos, ingredientes, preço por gr)
- Salgado (nome, tipo de salgado: frito; assado; lanche pronto, ingredientes, preço por
unidade)
Para cada categoria deve-se ter um formulário específico e os dados devem ser salvos em seus
respectivos arquivos: paes.txt, confeitaria.txt e salgado.txt.
